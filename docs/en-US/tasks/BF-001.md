# BF-001 — Initialize project

[Português (Brasil)](../../pt-BR/tasks/BF-001.md)

## Objective and context

Create a runnable BarberFlow foundation in an empty directory, following the reference stack. Initial state: no files or local Git.

## Scope

Next.js App Router, React, TypeScript strict, Tailwind, ESLint, Prettier, npm lockfile, development/validation scripts, responsive Portuguese landing page and minimal architecture, API, database, development and roadmap documentation.

## Out of scope

Database, authentication, CRUD, bookings, operational mock data, PWA, deployment and external services. Do not install dependencies for future features.

## Relevant files

package.json, package-lock.json, tsconfig.json, next.config.ts, eslint.config.mjs, .prettierrc.json, src/app, README.md and docs.

## Acceptance criteria

- `npm ci` installs on Node.js 24.
- Lint, typecheck and formatting pass.
- Build produces production artifacts.
- Production `/` returns HTTP 200 with BarberFlow title and pt-BR language.
- One-column mobile layout and grid on larger screens, without controls promising unavailable functionality.
- Credentials/generated artifacts are ignored; `.env.example` can be tracked.
- Documentation distinguishes implemented behavior from plans.
